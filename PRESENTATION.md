# 45-second pitch

> Esto es una prueba corta de cómo Explore puede dejar de mandar al usuario a Waze o Google Maps. El mapa es open source y el routing también. Aquí tenemos dos rutas reales: la más rápida y la más corta. Podemos cambiar el destino, recalcular y empezar una navegación básica. En producción la misma idea se conecta al GPS del teléfono con Ferrostar para rerouting y turn-by-turn. Lo importante es que la capa queda dentro de Explore, y después podemos agregar una tercera opción propia: **Explore Route**, que optimice no solo tiempo o distancia, sino lugares, seguridad, experiencias y rutas de nuestra comunidad.

## What this proves

- We can own the navigation UX.
- We can compute fastest and shortest routes without Google Maps/Waze as the core engine.
- We can keep users inside Explore.
- The architecture has a clear mobile production path.

## What it does not claim yet

- Waze-level live traffic
- production-grade tile/routing SLA
- voice navigation
- automatic off-route rerouting from device GPS
- background navigation

Those belong to the production phase.
